NumPy

NumPy is the array library underneath pandas and scikit-learn. Most model inputs end up as an ndarray.

Why an array instead of a Python list?

An ndarray stores one dtype in a contiguous block and runs numeric work in compiled loops. A list stores pointers to Python objects, so a sum over a list is a Python loop. scikit-learn converts tabular input to arrays before fit.

What do shape, ndim, dtype, and axis mean?

ndim is the number of dimensions. shape is the length of each one. A table of 500 rows and 4 features has shape (500, 4). dtype is the type of every element, such as float64.

axis=0 runs down the rows and collapses them, leaving one value per column. axis=1 runs across the columns and leaves one value per row. X.mean(axis=0) is the mean of each feature.

What are the broadcasting rules?

NumPy lines shapes up from the last dimension. Two sizes match when they are equal, or when one of them is 1. A missing dimension is treated as 1. A column of shape (n, 1) can be subtracted from a table of shape (n, p). A shape of (3,) and a shape of (4,) do not broadcast.

When is a slice a view, and when is it a copy?

A basic slice is a view: changing the slice changes the original array. Boolean masks and fancy index lists return a copy. Call .copy() when a later step must leave the source array alone. Two names pointing at one view are a common source of training-data bugs.

How do you index rows you care about?

X[X[:, 0] > 0] keeps rows where the first feature is positive. X[[0, 2, 5]] picks those positions and returns a copy. X[10:20] is a view of ten consecutive rows.

What is the difference between *, dot, and @?

* is element by element. @ and np.matmul are matrix multiplication. np.dot on two 1-D vectors is the inner product, and on two 2-D arrays it matches @. A prediction X @ coef_ + intercept_ is a matrix product, not an elementwise product.

How do you shape a vector the way a model expects?

A single feature of length n has shape (n,). scikit-learn wants (n, 1). x.reshape(-1, 1) makes that column. One sample with p features should be (1, p), not (p,), or predict will read the length as the number of samples.

Which functions come up next to a model?

  • np.argmax turns a row of class scores into a class index.
  • np.where(condition, a, b) builds a column from a rule.
  • np.unique lists the classes and their counts.
  • np.isnan finds missing numeric values. The mean of a slice that contains a NaN is NaN. np.nanmean skips those entries.
  • np.random.default_rng(seed) is the current random API. Pass the seed when an interviewer asks for a repeatable split or sample.

pandas

pandas is the table you clean before you hand columns to scikit-learn. A DataFrame is labeled rows and columns. A Series is one column with an index.

What is the difference between loc and iloc?

loc selects by label. A label slice includes the end: df.loc[0:5] keeps every label from 0 through 5. iloc selects by position and excludes the end, like Python: df.iloc[0:5] is the first five rows. Use loc when the condition is about values. Use iloc when the condition is about position.

How do you filter, update, and avoid a silent failed write?

df.loc[df["age"] > 30, "income"] filters and selects a column in one operation. Chained indexing such as df[df["age"] > 30]["income"] = 1 can write into a temporary copy and leave the original frame unchanged. That is the SettingWithCopy problem. Put the row filter and the column assignment in the same loc.

How does groupby work?

It splits the rows by a key, computes something on each group, and combines the results. df.groupby("city")["sales"].mean() returns the mean sales per city. .agg(["mean", "count"]) computes several summaries. as_index=False keeps the key as a normal column, which is what you want if that column will be a feature later.

When do you merge, and when do you concat?

pd.merge matches rows by key, the way a SQL join does. how="left" keeps every row of the left table. how="inner" keeps only matching keys. pd.concat stacks tables that already share columns: axis=0 adds rows, axis=1 places frames side by side by index.

If both sides have duplicate keys, a merge multiplies rows. A customer table joined to a purchases table on a non-unique customer id becomes one row per purchase. Check validate="many_to_one" when you believe the right-hand key is unique. A sudden jump in row count after a merge is the symptom interviewers expect you to name.

How do you handle missing values and bad types?

df.isna().sum() counts missing cells per column. dropna removes rows or columns. fillna fills them. For a model, prefer an imputer inside a scikit-learn pipeline so the fill value is learned on the training fold only.

pd.to_numeric(series, errors="coerce") turns junk strings into NaN. select_dtypes(include="number") isolates columns a linear model can use. Object columns that look numeric are a common reason fit fails.

Why do interviewers dislike a reflexive apply?

Series.map replaces each value from a dictionary or function. DataFrame.apply runs a function down a column or across a row in Python. DataFrame.map is the elementwise version. A column expression such as df["a"] / df["b"] stays in vectorized code and is the one to reach for first. Use apply when the operation really needs a whole row.

Should you one-hot encode with get_dummies?

pd.get_dummies is fine for a quick look at one table. It learns categories from whatever frame you pass, so the train and test matrices can grow different columns. OneHotEncoder inside a pipeline stores the training categories and applies them to later data. Say that when the question moves from exploration to a model you would ship.

What do you check before fit?

  • Each row is one sample, each feature column is a model input, and the target sits in y, not in X.
  • The index of X and y still describes the same rows after every filter and merge.
  • IDs, timestamps used as keys, and columns created from the target are out of X.
  • The train and test frames were split before any statistic was computed for imputation or scaling.

Matplotlib

Matplotlib draws the charts you use to explain a dataset and a model. In an interview, use the object-oriented form: one figure, one or more axes.

What is a figure, and what is an axes?

The figure is the whole canvas. An axes is one plotting panel on that canvas, with its own x and y scales. fig, ax = plt.subplots() creates both. fig, axes = plt.subplots(1, 2) creates two panels. Call methods on ax (ax.plot, ax.scatter, ax.bar, ax.hist) so several panels stay independent. plt.plot always targets the current panel, which gets ambiguous as soon as there are two.

What do you add so the chart can be read without you talking?

ax.set_xlabel, ax.set_ylabel, and ax.set_title name the encodings. ax.legend identifies each series you passed with a label. fig.tight_layout() keeps labels inside the canvas. fig.savefig("chart.png", dpi=150) writes the file. plt.show() opens a window.

How do scikit-learn plots fit on these axes?

For a model, prefer the display classes in scikit-learn. They compute the right values and draw onto a Matplotlib axes you pass in. ConfusionMatrixDisplay, RocCurveDisplay, and PrecisionRecallDisplay live in sklearn.metrics. LearningCurveDisplay lives in sklearn.model_selection. from_estimator(model, X, y, ax=ax) fits the drawing to a panel you already labeled. You still set the title and save the figure yourself.

Machine learning

This is the core interview material. NumPy, pandas, and Matplotlib get the data ready and make the result visible. scikit-learn is where the model, the split, and the metric live. The sections after this one go into the library in detail.

What kinds of learning are there?

Supervised learning fits a model to inputs X and known targets y. Classification predicts a category. Regression predicts a number. Unsupervised learning has no y. Clustering groups rows. PCA compresses features. Reinforcement learning is a different setup, with an agent and rewards, and it is outside scikit-learn.

What is a sample, a feature, and a parameter?

A sample is one row. A feature is one input column. A label is the target. Parameters are values the model learns during fit, such as coef_. Hyperparameters are choices you make before fit, such as max_depth or C. You choose hyperparameters with validation. You report parameters only after the model has been fit.

What is the bias-variance tradeoff?

Bias is error from a model that is too rigid to follow the pattern, such as a straight line through a curve. Variance is error from a model that changes a lot when the training rows change, such as a deep tree that memorizes them. Regularization, a shallower tree, or more data pulls variance down. A more flexible model pulls bias down. The validation score is how you see the balance. Training score alone cannot show it.

What are the three data roles?

  • Training data is what fit learns from.
  • Validation data is what you use to compare models and hyperparameters. Cross-validation builds these folds from the training portion.
  • Test data is touched once, after the model is frozen, to estimate performance on unseen rows.

Looking at the test score and then changing the model turns the test set into another validation set.

What baseline do you mention before any clever model?

For classification, the majority-class rate, or a DummyClassifier. For regression, predicting the training mean, or a DummyRegressor. A model that cannot beat that baseline has not learned the target. Interviewers use this to see whether you can judge a score.

What assumption fails first on real tables?

Most splits assume rows are independent and drawn from the same distribution as production. Time series break that: a random split trains on the future and tests on the past. Duplicate rows break it too, because the same sample lands in both train and test. A feature that was built using the label, or using records from later in time, breaks it as leakage.

What is the path from a table to a score?

  1. Clean and join in pandas. Drop identifiers and any column that contains the answer.
  2. Split into train and test before fitting anything.
  3. Put imputation, encoding, scaling, and the estimator in one Pipeline.
  4. Choose the metric from the cost of a mistake, and compare against the baseline with cross-validation.
  5. Fit the chosen pipeline on the full training set and score it once on the test set.
  6. Plot the confusion matrix, the ROC or precision-recall curve, or the residuals, and say what the errors are.

What scikit-learn is

What is scikit-learn?

A Python library for classical machine learning. You import it as sklearn. It covers supervised models, clustering, dimensionality reduction, preprocessing, model selection, and metrics. It expects tabular data: X with shape (n_samples, n_features), and y with shape (n_samples,).

What does it leave to other libraries?

Deep learning, GPU training, and large-scale distributed training. scikit-learn is the usual choice for structured data and models that fit in memory.

What is an estimator?

Any object that learns from data through fit. After fitting, it can predict or transform.

The estimator API

What methods should you know?

Where do parameters live?

You pass hyperparameters to the constructor: C, max_depth, n_estimators. Values learned during fit are stored on attributes that end with _: coef_, intercept_, feature_importances_, classes_.

Why does every model share this API?

So models, preprocessors, cross-validation, and pipelines can be swapped without rewriting the training loop. get_params and set_params are what GridSearchCV and Pipeline use to clone an estimator and set nested parameters.

Data and leakage

What is the first split you make?

Hold out a test set with train_test_split before any fitting. Fit every scaler, encoder, imputer, and model on the training split only. Transform the test split with those already fitted objects.

What is data leakage?

Information from the test set, or from the future, reaching the model during training. The score then looks better than production performance. Typical causes:

  • Fitting a scaler on the full dataset, then splitting.
  • Choosing features by looking at the whole dataset, including the test rows.
  • Tuning hyperparameters on the test set.
  • Filling missing values with a statistic computed from all rows.
  • Time-series data split at random, so later rows train a model that is tested on earlier rows.

How do you split time-series data?

Cut by time. Train on the past, test on a later window. Use TimeSeriesSplit for cross-validation. A random split lets the model see the future.

Why pass stratify=y?

So each split keeps the same class proportions as the full dataset. This matters when one class is rare. A random split can put almost all of the rare class into one side.

Why set random_state?

So the split and any stochastic model can be reproduced. Interviews often expect you to mention it when you talk about comparing two models.

Preprocessing

Which models need scaled features?

Models that use distances or a linear penalty on coefficients: linear and logistic regression, SVM, k-nearest neighbors, k-means, and PCA. A feature on a scale of thousands otherwise dominates one on a scale of 0 to 1.

Tree models split on one feature at a time, so StandardScaler does not change their splits. Random forests and gradient boosting do not need scaled numeric inputs.

StandardScaler or MinMaxScaler?

StandardScaler subtracts the mean and divides by the standard deviation. Use it as the default for linear models and SVMs. MinMaxScaler maps each feature to a fixed range, usually 0 to 1. Use it when you need bounded inputs. Both learn their statistics in fit, so fit them on the training data only.

How do you encode categories?

OneHotEncoder makes one binary column per category. Use it for nominal categories, where no order exists. Set handle_unknown="ignore" if the test set may contain a new category. OrdinalEncoder maps categories to integers. Use it when the order is real, or when a tree model can split on the codes. An arbitrary integer coding fed to a linear model invents a fake order.

What is the dummy-variable issue?

One-hot columns sum to 1, so they are perfectly collinear with an intercept. For a linear model, drop one category (drop="first") or remove the intercept. Tree models can keep every column.

How do you impute missing values?

SimpleImputer fills with the mean, median, or most frequent value learned from the training data. Put the imputer inside a pipeline so each cross-validation fold computes its own fill value. The median is the safer default for numeric features that contain outliers.

Linear and logistic regression

What does linear regression learn?

Weights coef_ that minimize squared error between X @ coef_ + intercept_ and y. LinearRegression.score returns R².

What do Ridge and Lasso add?

Both add a penalty so large weights are discouraged.

  • Ridge (Ridge, and logistic regression with l1_ratio=0) adds the sum of squared weights. Weights shrink toward zero and stay nonzero. It handles correlated features by sharing weight among them.
  • Lasso (Lasso, and logistic regression with l1_ratio=1) adds the sum of absolute weights. Some weights become exactly zero, so it also selects features.
  • Elastic net mixes the two. In logistic regression that mix is l1_ratio between 0 and 1.

In scikit-learn 1.9, LogisticRegression no longer takes penalty as the way to choose this. l1_ratio=0 is L2, l1_ratio=1 is L1, and C is the inverse of regularization strength. Smaller C means a stronger penalty. C=np.inf turns the penalty off.

What does logistic regression predict?

It models the log-odds of a class as a linear function of the features, then converts that to a probability with the logistic function. predict applies a threshold, default 0.5, to predict_proba. For more than two classes the default is multinomial: one linear function per class, then a softmax.

Can you interpret coef_?

In linear regression, a coefficient is the change in the prediction for a one-unit change in that feature, with the others held fixed. That reading depends on the feature's scale, so interpret coefficients after you state how the column was scaled. In logistic regression the coefficient is a change in log-odds. It is a change in the log of the odds, which is a different scale from a change in probability. Correlated features make individual coefficients unstable even when predictions stay good.

Trees and ensembles

How does a decision tree predict?

It asks a sequence of threshold questions on single features and sends each sample to a leaf. The leaf predicts the majority class, or the mean of the training targets in that leaf. An unpruned tree memorizes the training set. Limit it with max_depth, min_samples_leaf, or ccp_alpha.

Bagging or boosting?

Bagging trains many models on bootstrap samples and averages them. The trees are independent and can train in parallel. Random forests are bagged trees that also pick a random subset of features at each split (max_features="sqrt" for classifiers). Averaging reduces variance.

Boosting trains trees one after another. Each new tree focuses on the residual error of the ensemble so far. Gradient boosting shrinks each tree by learning_rate and adds it to the running prediction. Use enough trees (n_estimators or max_iter) together with a small learning rate. Boosting reduces bias and can overfit if you add too many trees or make each tree too deep.

Random forest or gradient boosting, in practice?

  • A random forest is a strong default, is hard to break, and trains trees in parallel. Important knobs are n_estimators, max_depth, and min_samples_leaf.
  • Gradient boosting often reaches a higher score after tuning. HistGradientBoostingClassifier is the faster implementation in current scikit-learn. It bins numeric features and can take categorical features when the column dtype is categorical. Important knobs are learning_rate, max_iter, and max_depth or max_leaf_nodes.

What is out-of-bag score?

Each random-forest tree leaves out about a third of the rows. Predicting those left-out rows gives an internal validation score without a separate holdout. Set oob_score=True. It is a useful check. A final reported number still comes from a test set the forest never saw.

Is feature_importances_ reliable?

It is a useful ranking, and it is biased toward features with more possible split points, including high-cardinality numeric columns and categories that were not grouped. For a claim you would defend, use permutation importance: shuffle one column and measure how much the score drops. That works on any fitted model and respects feature interactions better than a single coefficient.

SVM and neighbors

What is a support vector machine doing?

It looks for the boundary with the widest margin between classes. Points on the margin are the support vectors. C trades a wider margin for fewer margin violations. A small C allows a smoother boundary. The RBF kernel measures similarity by distance, so scale the features first. gamma controls how far a single training point influences the boundary. A large gamma can overfit.

How do you get probabilities from an SVM in 1.9?

SVC(probability=True) still works and is deprecated. It will be removed in 1.11. The current approach is CalibratedClassifierCV(SVC(), ensemble=False), which fits the SVM and then calibrates scores on held-out predictions. Say this if the interviewer asks for probabilities rather than labels.

When is k-nearest neighbors a weak fit?

Prediction scans neighbors, so it is slow at query time on large data. Distance is dominated by irrelevant features and by unscaled columns. It also stores the training set. It is a good baseline and a good choice when the decision really is local.

Unsupervised learning

What is k-means assuming?

You choose n_clusters. It alternates between assigning each point to the nearest centroid and moving each centroid to the mean of its points. Clusters are treated as spherical and of similar size. Scale the features first, because the algorithm uses Euclidean distance. The result depends on the initial centroids, so run it with several initializations (n_init) and keep the lowest inertia. Inertia always falls as k grows, so the elbow is only a heuristic. Check cluster stability and whether the groups are useful.

What is PCA for?

It finds orthogonal directions of highest variance and projects the data onto the first k of them. Use it to compress features, to visualize, or to remove linear correlation before a distance-based model. Scale features first, or a large-range column dominates the variance. PCA does not look at y. A direction with low variance can still be the one that separates classes. For supervised reduction, select features with the target, rather than keeping the top principal components only because they explain variance.

Metrics

Which classification metric do you report?

Match it to the cost of errors.

  • Accuracy is the fraction of correct labels. It hides failure on a rare class. If 99% of rows are negative, a model that always predicts negative scores 0.99.
  • Precision is the fraction of positive predictions that are truly positive. Use it when a false positive is expensive.
  • Recall is the fraction of actual positives that you caught. Use it when a false negative is expensive.
  • F1 is the harmonic mean of precision and recall. Use it when you care about both and the classes are uneven.
  • ROC-AUC measures how well the score ranks positives above negatives, across thresholds. Feed it scores or probabilities. Hard labels throw away the ranking. It can look strong when the negative class is huge, because false positives are diluted.
  • Precision-recall AUC is the ranking metric to prefer when positives are rare.
  • A confusion matrix is what you show when someone asks which classes are being mixed up.
  • Log loss punishes confident wrong probabilities. Use it when the probabilities themselves matter.

What threshold do you use?

predict uses 0.5. If false negatives and false positives have different costs, sweep the threshold on a validation set using predict_proba, pick the threshold there, and apply that same threshold to the test set once.

Which regression metric do you report?

  • MAE is the average absolute error, in the units of y. It is easy to explain and resists outliers.
  • MSE and RMSE punish large errors more. RMSE is in the units of y.
  • R² is the fraction of variance explained relative to predicting the mean. R² of 0 matches the mean baseline. Negative R² is worse than predicting the mean.

Validation and tuning

Why cross-validate?

One split can be lucky. cross_val_score refits the model on several folds and reports the mean and spread. Use stratified folds for classification. The test set stays untouched until the model and its hyperparameters are frozen.

Where does the test set enter?

Once. After you have chosen the model, the preprocessing, and the hyperparameters using training data and cross-validation. If you look at the test score and then change the model, that set has become another validation set.

GridSearchCV or RandomizedSearchCV?

GridSearchCV tries every combination you list. Use it when the grid is small. RandomizedSearchCV samples combinations. Use it when you have many hyperparameters, and spend the budget on the ones that matter most: C, max_depth, learning_rate, n_estimators. Both refit the best parameters on the full training set by default.

What must sit inside the search?

The entire pipeline, including scaling and imputation. If you scale first and then cross-validate the model only, every fold's scaler has seen the validation rows.

How do you tell overfitting from underfitting?

Compare training score and validation score.

  • Both scores are poor: the model is too simple, the features are weak, or the target is noisy. Add features, use a more flexible model, or reduce regularization.
  • Training score is high and validation score is much lower: the model memorized the training set. Constrain it with max_depth, min_samples_leaf, stronger regularization (smaller C), fewer boosting iterations, or more data.

A learning curve plots score against training-set size. A gap between train and validation that shrinks as data grows points to collecting more data. A gap that stays open points to simplifying the model.

Pipelines

Why use a pipeline?

Pipeline chains preprocessing and a final estimator. fit runs each step in order. predict runs every transformer, then the model. Cross-validation clones the whole pipeline per fold, so preprocessing cannot see the validation rows. It is also the clean object to save and deploy, because the scaler travels with the model.

A column transformer applies different steps to numeric and categorical columns, then concatenates the results. The usual pattern is impute and scale the numeric columns, and impute and one-hot encode the categorical columns.

How do you name parameters in a grid?

Use the step name, two underscores, then the parameter: clf__C, prep__num__scaler__with_mean. That double underscore is how set_params addresses nested estimators.

Imbalance, calibration, and saving

The positive class is 1% of the data. What do you change?

Keep a stratified split. Report recall, precision, and the precision-recall curve, and treat accuracy as a secondary number. Practical levers inside scikit-learn are class_weight="balanced", which up-weights the rare class in the loss, and a threshold chosen for the recall you need. Getting more positive examples, or cleaner features, usually beats a clever sampler.

What is probability calibration?

A model can rank well and still produce probabilities that do not match observed frequencies. A random forest's probabilities are often pushed away from 0 and 1. An SVM score is a margin, which is a different quantity from a probability. CalibratedClassifierCV fits a mapping from scores to probabilities with Platt scaling or isotonic regression, using out-of-fold predictions so the mapping is fit on rows the model did not train on.

How do you save a model?

skops or the versioned pickle path documented by scikit-learn. Loading a pickle is equivalent to running code, so load only files you trust. Record the scikit-learn version with the file. A pipeline saved after fit includes the fitted scaler and encoder.

Follow-up questions

Why can cross-validation still be biased?

If you used the validation scores to pick features or a model family, those scores are optimistic. Nested cross-validation puts the search in the inner loop and the evaluation in the outer loop. Mention it when the interviewer asks for an unbiased estimate. For a single final number, a held-out test set that was locked before selection is the simpler answer.

Two models score 0.91 and 0.92. Which do you ship?

Ask for the metric, the variance across folds, the latency, and the cost of a mistake. A 0.01 gap inside the fold-to-fold noise is a weak reason to take the more complicated model. If the scores are stable and the metric matches the business cost, take the higher one and confirm once on the test set.

A categorical column has a new level in production. What happens?

With the default OneHotEncoder(handle_unknown="error"), transform fails. Set handle_unknown="ignore" so the new level becomes an all-zero row, and monitor how often that happens. An all-zero row is a silent fallback, so it deserves an alert.

Why might a tree beat a tuned logistic regression on the same table?

The target depends on thresholds and interactions, which a tree represents directly. A linear model needs you to build those interactions as columns. If a linear model wins, the relationship is close to linear and the coefficients are easier to explain.

What do you check before you trust a high score?

Confirm the split happened before fitting, the metric matches the decision, a simple baseline was beaten by enough to matter, and both the training and validation scores are healthy. Then look for duplicate rows and for a column that copies the target or a unique id. Either one can make any model look perfect.

How do you say this in an interview?

A tree is what I show the process engineer, because each split is a threshold on current or time.” Then name the metric: recall on bad welds if a miss is expensive, precision if a false stop is what they feel.

What does leakage look like on a vehicle?

A column that exists only after the event you are predicting. “Parts replaced” cannot be an input to “will this visit find a brake fault.” The odometer reading from next month cannot predict this month’s failure. A random split across a vehicle’s life trains on later visits and tests on earlier ones. Split by time, or by vehicle, so the same car is not in both sets. A new model year is a new distribution. A score from last year’s fleet is not evidence about this year’s parts.

Why is accuracy a weak number here?

Most vehicles do not fail. A model that always says “healthy” looks accurate and catches nothing. Report recall and precision on the failure class, or the precision-recall curve. Keep the split stratified. class_weight="balanced" and a threshold chosen for the recall the plant or the workshop needs are the levers inside scikit-learn. A missed weld and a missed brake-wear call are the rare class you actually care about.

Where do the other topics show up?

  • Vision on the line: a camera flags paint defects, missing clips, or a wrong badge. That is classification or detection, usually a fine-tuned network, scored with intersection over union when the output is a box.
  • Language: technician notes and owner complaints. Bag of words is the baseline. A transformer is the step up when the phrases get long and the categories overlap.
  • Recommenders: which service operation to offer, or which spare part a dealer should stock, ranked for a short list and beaten against “most replaced this month.”
  • MLOps: log the features seen at the station, the model version, and the later label from audit or from the workshop. A new model year is drift. Shadow the new model on the line before it can fail a vehicle.

What stays outside these labs?

Brake actuation, steering, and airbag firing are certified control systems. A scikit-learn model can support inspection, maintenance timing, pricing, and complaint routing. A person or a certified controller owns the safety action. Say that boundary when the interviewer pushes the use case toward the driving task. Perception for driver assistance is a separate system, with its own data, latency budget, and safety case. It is not a drop-in replacement for these tables.

Statistics and probability

These answers sit under almost every modeling discussion. Say the definition, then the mistake the interviewer is listening for.

What is a random variable, and what are expectation and variance?

A probability is a number from 0 to 1 attached to an event. A random variable assigns a number to an outcome. The expectation is the probability-weighted average of those numbers. The variance is the expected squared distance from that average. The standard deviation is the square root of the variance, so it is in the same units as the variable. A sample mean and a sample standard deviation are estimates of those two quantities from the rows you have.

What does the central limit theorem let you say?

The mean of many independent draws, after you center and scale it, is approximately normal even when each draw is not. That is why a confidence interval for a mean often uses a normal or t critical value once the sample is reasonably large. The theorem says nothing about a single row being normal. A tiny sample, or strong dependence between rows, is outside what it buys you.

What does a confidence interval mean?

A 95% confidence interval comes from a procedure that, repeated on new samples from the same process, covers the true parameter about 95% of the time. Once you have computed one interval, the parameter is either inside it or not. The interval is a statement about the procedure. A wider interval means a noisier estimate or a higher confidence level. A larger sample narrows it, roughly with the square root of the sample size. Report the interval next to any point estimate. A p-value alone hides the size of the effect.

What is a hypothesis test, and what is a p-value?

You state a null hypothesis, usually “no difference” or “no effect,” and a test statistic. The p-value is the probability of a statistic at least as extreme as the one you observed, if that null were true. A small p-value is evidence against the null. It is the probability of the data under the null, which is a different claim from the probability that the null is true. A large sample can make a tiny, useless difference look significant. Say the estimate and the interval, and say whether the difference is large enough to matter.

What is a Type I error, a Type II error, and power?

  • A Type I error rejects a true null. That is a false positive. The significance level, often 0.05, is the rate of that error you are willing to accept.
  • A Type II error fails to reject a false null. That is a false negative.
  • Power is the probability you detect an effect of a size you stated in advance. More data, a larger real effect, or a looser significance level raises power.

Which test do you name?

QuestionA test to say out loud
Compare the mean of one numeric outcome across two groupsTwo-sample t-test. Welch’s version avoids assuming equal variance.
The same units measured twicePaired t-test on the differences.
Two categorical columns, “are they associated?”Chi-square test on the contingency table. Fisher’s exact test when the counts are very small.
One numeric outcome, three or more groupsANOVA asks whether any mean differs. A planned comparison then says which pair.
Two numeric columnsPlot them first. Pearson correlation measures a linear association. Spearman measures a monotone one.

Check the shape and the sample size before you lean on a t-test. Name the plot even when they asked for the test.

What is Bayes’ rule in one sentence?

The posterior is proportional to the likelihood times the prior. You update what you believed by how well it predicted the data you saw. A spam filter is the usual example: the prior is how common spam is, and the likelihood is how typical the words are under spam and under ordinary mail. The base rate matters. A rare event can produce mostly false alarms even when the detector is accurate on both classes.

How do you separate correlation from causation?

Correlation is a symmetric association. A causal claim needs a reason the association is not a confounder, selection, or the arrow running the other way. Name a confounder, say what you would hold fixed, or describe the experiment you would run. Random assignment is the clean support for a causal claim. Observational data can support one under stronger assumptions, and you should say what those assumptions are.

What goes wrong when you run many tests?

Each test at 0.05 has a 5% false-positive rate under the null. Twenty independent null tests expect about one false rejection. If you searched many features or many metrics, say so. Bonferroni divides the significance level by the number of tests. It is simple and conservative. The same instinct applies to peeking at a test set until the score looks good.

SQL

Interview SQL is about grain, joins, and aggregation. Say which row the answer is supposed to contain before you write the query.

What order does a query run in?

FROM and JOIN build the row set. WHERE filters rows before aggregation. GROUP BY collapses rows. HAVING filters groups. SELECT chooses the columns. ORDER BY sorts. LIMIT cuts the result. WHERE cannot see an aggregate. HAVING can. A SELECT alias is available in ORDER BY, and it is often unavailable in WHERE.

Which join do you use?

  • INNER JOIN keeps keys that appear on both sides.
  • LEFT JOIN keeps every row from the left table and fills NULL when the right side has no match. Use it for “customers with no orders.”
  • FULL OUTER JOIN keeps unmatched rows from both sides.
  • A cross join pairs every left row with every right row. It is rarely what you want unless you mean to build a grid.

An inner join that was supposed to be a left join silently drops the rows the question was about.

Why did the join duplicate rows?

The join key was not unique on one side. One customer with three orders becomes three rows. Decide the grain first: one row per customer, or one row per order. Aggregate to that grain before the join, or join and then aggregate. Count rows before and after the join when a number looks too large.

How do you handle NULL?

NULL means unknown. It is a different value from zero and from an empty string. col = NULL never matches. Use IS NULL. COUNT(col) skips nulls. COUNT(*) counts rows. SUM skips nulls. A null join key does not match, so those rows disappear from an inner join.

What is a window function for?

It computes a value across related rows and keeps every row. ROW_NUMBER() OVER (PARTITION BY user_id ORDER BY ts) numbers events inside each user. SUM(amount) OVER (PARTITION BY user_id ORDER BY ts) is a running total. LAG(amount) over the same window is the previous row’s value. Reach for a window for “second purchase,” “change since yesterday,” and “top n per group.”

How do you return the second highest value, including ties?

Rank the rows and filter. RANK gives ties the same number and skips the next number. DENSE_RANK gives ties the same number and does not skip. ROW_NUMBER breaks ties arbitrarily, so it is the wrong tool when ties should stay together. A subquery that takes the maximum strictly below the overall maximum also works, and you should say how ties are treated.

What does an index change?

An index lets the database find matching rows without reading the whole table. It speeds a selective filter, a join, and an ordering on that column. Writes get slower because the index has to be updated. Name an index when a query is slow and the predicate is selective. Indexing every column is a cost, not a default.

What is a CTE, and how do you answer a retention question?

A WITH clause names a subquery so the rest of the statement can read it. Use it to show the steps: filter activity, aggregate to user and day, then compute the rate. A retention answer is a cohort of users active on day 0, and the fraction also active on day 7. Build it at the grain of user and date, then aggregate. A self-join on user id with a seven-day gap, or a window over each user’s activity, both work. Say “distinct users,” because raw event rows would count someone twice.

Deep learning

Stay at the level of the training loop, the shape of the model, and how you would know it failed. Derivations are a follow-up, not the opening.

When do you reach for a neural network?

When the raw input is an image, audio, or a long piece of text, and you have enough labels or a pretrained model to start from. On a few thousand tabular rows, a gradient-boosted tree is usually the stronger and simpler model. Say that comparison before you describe a network.

What is a layer doing?

A dense layer computes a weighted sum of its inputs, adds a bias, and applies a nonlinearity. Without the nonlinearity, a stack of layers is still one linear function. ReLU is the usual hidden activation. A sigmoid on the last layer is a single probability, or one probability per label when labels are independent. Softmax is for classes that are mutually exclusive: the outputs are positive and sum to 1.

What do you minimize, and what is backpropagation?

A loss. Cross-entropy for classification, squared error for regression. Training changes weights to reduce the average loss on the training set. Backpropagation applies the chain rule so each weight receives a gradient of that loss. The optimizer steps the weights in the opposite direction. You can describe that loop without writing the derivatives. If they ask, the gradient is with respect to the loss, and it flows from the output back toward the input.

What is a minibatch, and what does the learning rate do?

A minibatch is a subset of rows used for one gradient estimate. A larger batch gives a steadier estimate and uses more memory. The learning rate is the step size. Too large and the loss diverges. Too small and training crawls. Adam adapts a step size per parameter and is a common default. SGD with momentum is still what many vision recipes use once the schedule is tuned. An epoch is one pass over the training set.

How do you tell a network it is memorizing?

The same gap as in classical models: training loss keeps falling while validation loss rises or stalls. The levers are more data, augmentation, weight decay, dropout, a smaller model, and early stopping. Dropout randomly zeros hidden units during training so one path cannot carry the prediction. It is off at inference. Early stopping keeps the weights from the epoch with the best validation loss. Weight decay penalizes large weights, in the same spirit as ridge.

What is a vanishing gradient?

In a deep stack, especially with sigmoids, the gradient that reaches the early layers shrinks toward zero, so those layers barely move. ReLU, careful initialization, and residual connections are the usual replies. A residual block adds the block’s input to its output, which gives the gradient a path that does not pass through every weight.

What is batch normalization doing?

It standardizes a layer’s activations using the mean and variance of the current minibatch, then learns a scale and a shift. Training is more stable, and a larger learning rate is often possible. At inference the layer uses running statistics collected during training, because a single request is not a minibatch.

What is a convolution, and what is attention?

A convolutional layer slides a small filter across the input and reuses the same weights at every position. That fits images: the same edge detector is useful in every corner, and each output sees only a local patch. Stride or pooling reduces the spatial size.

Attention lets a position look at other positions. Each token builds a query, a key, and a value. The weights are a softmax over how well the query matches the keys, and the output is a weighted sum of the values. Self-attention means the queries, keys, and values all come from the same sequence. A transformer stacks that, which is why it replaced step-by-step recurrence for most language models.

What is transfer learning?

Start from a model trained on a large related task. Train the new last layer on your labels, or train the whole network at a small learning rate. This is the default when you have hundreds or a few thousand examples rather than millions. Keep the preprocessing the pretrained model expects.

Natural language processing

How do you represent text for a classical model?

Tokenize, then bag of words or TF-IDF, then a linear classifier. Bag of words counts tokens and ignores order. TF-IDF down-weights tokens that appear in almost every document. Say this baseline before a transformer when the task is topic classification on short documents. Character n-grams are the fallback when words are misspelled or mixed-language.

What is an embedding?

A learned vector for a token. Tokens that share contexts end up nearby. A static embedding is one vector per word type. A transformer builds a vector per token in context, so the same spelling beside different neighbors gets different vectors. The vectors are parameters, trained with the rest of the model or taken from a model someone else trained.

What is tokenization in a modern model?

Text is split into subwords from a fixed vocabulary, often byte-pair encoding or WordPiece. A rare word becomes several pieces. The model cannot emit an id outside that vocabulary. The same tokenizer has to be used when you train and when you serve. A mismatch there is a silent bug: the ids still look like integers.

When do you say BERT, and when do you say a decoder model?

An encoder such as BERT reads the whole span and was trained to fill in masked tokens. It is the usual start for classification, named-entity recognition, and extractive question answering. A decoder such as GPT was trained to predict the next token, and it is the usual start for generation. A sequence-to-sequence model, encoder plus decoder, fits translation and summarization. Name the task, then the family.

Do you fine-tune, prompt, or retrieve?

  • Fine-tuning continues training on your labeled pairs and changes weights. Use it when you have labels and need a stable, cheaper model at request time.
  • Prompting leaves the weights fixed and puts the instruction, and sometimes a few examples, in the input. Use it when labels are scarce or the task changes often.
  • Retrieval-augmented generation fetches passages and puts them in the prompt, so the answer can be tied to a source. Use it when the facts change, or when guessing from parameters is unacceptable.

Which metric do you report for text?

For classification, precision, recall, and F1, often per class. For generation, BLEU and ROUGE score overlapping n-grams against a reference. They are weak proxies for whether the answer is true or useful. For a product, prefer a check that matches the decision: a required field is present, a human rating on a sample, or an exact match on a closed answer set.

What fails first with text data?

A random split leaks when the same document, user, or template is on both sides. A label that is a keyword inside the text produces a perfect score and a model that does nothing new in production. Very common tokens dominate a bag-of-words model unless you down-weight them. Deduplicate near-copies before the split.

Computer vision

How is an image an input?

A height-by-width-by-channels array. A color photo has three channels. Values are scaled into a small range, and a pretrained model expects the same normalization it was trained with. A shape mismatch or a channel order mismatch (RGB versus BGR) is a common reason a fine-tune looks randomly initialized.

Which vision task is it?

  • Classification assigns one label to the image.
  • Object detection assigns a label and a box to each object.
  • Semantic segmentation assigns a label to each pixel.
  • Instance segmentation separates individual objects as well as labeling their pixels.

Name the task before the architecture. An image-level accuracy number does not answer a detection product.

What does a CNN learn, and what is augmentation?

Early filters respond to edges and simple patterns. Later layers see a larger region and combine those into parts. You describe that hierarchy. You rarely defend a story about one filter.

Augmentation applies label-preserving changes to training images only: crops, flips, mild color changes. It expands the training set and reduces overfitting. A horizontal flip is wrong when left and right mean different things, including text in the image and some medical findings.

How do you fine-tune a vision model?

Take a backbone trained on a large classification set, replace the final layer with your number of classes, and train that layer first. If you have more labels, unfreeze later stages of the backbone at a smaller learning rate. Freeze batch-norm or keep the batches large enough that its statistics are stable. Use the backbone’s preprocessing unchanged.

How do you score a detector?

Intersection over union is the overlap of the predicted box and the true box, divided by their union. A prediction counts as a true positive when the class matches and the IoU clears a threshold, often 0.5. Average precision summarizes the precision-recall curve for one class. Mean average precision averages that across classes, often over several IoU thresholds. A confidence threshold still has to be chosen for the operating point you will ship.

The test score is high and the product is wrong. What do you check?

The test images look like the training images, and production does not: a different camera, lighting, crop, or resolution. A rare class is being ignored by an accuracy metric. The product needs a box and you reported image-level accuracy. Resize or augmentation is cutting off the object. Look at the errors, not only the average.

Recommendation systems

What are you predicting?

Explicit feedback is a rating the user gave. Implicit feedback is a behavior: a click, a watch, a purchase. Most product recommenders are implicit. A missing event is not a clean negative, because the user may never have been shown the item. Say how you will treat missing pairs before you name a model.

Content-based or collaborative filtering?

Content-based scoring uses item attributes and the attributes in the user’s history. A brand-new item can be scored on day one. Collaborative filtering uses overlap in who interacted with what. It needs that overlap, and it often finds taste that attributes miss. A new user or a new item with no interactions is the cold-start problem. A hybrid uses content until interactions exist, then blends in the collaborative score.

What is matrix factorization?

Each user and each item gets a vector of latent factors. The predicted score is their dot product, plus user and item biases. You learn the vectors from observed interactions, which compresses a sparse user-by-item matrix. Similar users end up with similar vectors because they interacted with similar items. The factors are rarely a clean explanation you would show a user.

How do you serve a ranked list?

A retrieval stage gathers a few hundred candidates quickly: a popularity list, an approximate nearest-neighbor index over item vectors, or a retrieval model. A ranker then orders those candidates with a richer model and fresher features. Scoring every item in the catalog with the heavy model on every request is usually too slow. Say the latency budget when you draw this.

Which metric, and what has to be beaten?

Precision at k and recall at k, because the user sees a short list. NDCG at k rewards a relevant item higher in that list. The baseline is popularity, such as “most watched this week.” An offline win can still fail if the list is repetitive or full of items the user already knows. Confirm with an online test on the product metric: watches, purchases, or retention, not only click-through.

How do you split recommender data?

By time. Train on earlier interactions and test on later ones. A random mask lets the model train on a user’s future and test on their past. If the product should not show something the user already consumed, remove those items from the candidate list at evaluation too.

System design and MLOps

Open with the decision, the latency, and the cost of a mistake. The diagram comes after that.

How do you open a design question?

Clarify what decision the model supports, how fast the answer is needed, how many requests, and what a wrong prediction costs. Then name the label, the metric, a baseline, where training data comes from, how a prediction is served, and what you monitor. That outline is the answer they are grading. The model family is one line inside it.

Batch scoring or online scoring?

Batch scoring writes predictions on a schedule, such as nightly churn scores into a table. Use it when the decision can wait. Online scoring runs inside the request, such as fraud at checkout. Online needs a latency budget, features that exist at request time, and a fallback when the model times out. The fallback is often a simple rule or the previous model, and you should name it.

What has to match between training and serving?

The feature definitions, the preprocessing, and the code path where you can share it. A scikit-learn pipeline carries the scaler and encoder with the model. A common failure computes a feature from the full table in training and from a different window in production. A column that appears only after the event, such as “refund issued,” cannot be an input at decision time. This is leakage, moved into the serving path.

What do you log?

The features the model actually saw, the score, the threshold, the model version, and the label when it arrives later. Without the inputs you cannot reproduce a bad prediction. Without the version you cannot tell a code change from a data change. Labels for fraud or churn often arrive days later, so the metric you monitor is delayed on purpose.

What is drift, and when do you retrain?

Data drift means the inputs moved. Concept drift means the relationship between inputs and the label moved. Monitor feature distributions, the score distribution, and, once labels arrive, the metric. Retrain when that metric drops for a reason you can name, on a schedule if the world moves steadily, or both. A retrain on corrupted fresh data is worse than keeping the previous model. Keep the previous artifact so you can roll back.

How do you ship a new model?

  • Shadow: the new model scores live traffic and you only log it. The old model still decides.
  • Canary: a small fraction of decisions use the new model, with a fast rollback.
  • A/B test: users are assigned at random, you watch a product metric, and you decide with a stopping rule. Use this when the model changes what a person sees.

Roll back by switching the model version. Retraining in place during an incident destroys the thing you might need to restore.

What do you keep so a run can be repeated?

The code version, the data snapshot or the query that built it, the hyperparameters, the metrics, and the saved artifact. A weight file without the library version and the feature definition is not a reproducible run. For a classical model, save the fitted pipeline. Record the scikit-learn version beside it, and load only artifacts you trust.

Behavioral questions

These are scaffolds. Put a real project in each one. A stack of model names without a decision is a weak answer.

How do you structure the answer?

Situation, task, action, result. One concrete project. What you personally did, separate from what the team did. A number if you have one. What changed afterward. About two minutes, then stop. Let them pull on a thread. If you cannot say what you would redo, the story is not finished.

Tell me about a project.

Name the decision the model supported, the data you had, the baseline, the metric, and the result. Include one thing that went wrong and the check that caught it. Close with what shipped and what you left out on purpose. Interviewers trust the project more when the omission is a judgment call, such as skipping a heavier model that did not beat the baseline by enough to matter.

Tell me about a mistake.

Pick a real one with a contained cost. State the assumption, the signal you missed, the process you changed, and how you checked the fix. A leaked feature, a metric that did not match the decision, or a split that mixed time are all fair material. A story that blames someone else, or a story where nothing broke, does not answer the question.

You disagreed with a stakeholder. What happened?

State their goal and yours in their words. Show the comparison you brought: a baseline against the model they asked for, or the metric they actually use to judge success. Say what you conceded. End with the decision that was made and who owned it. The point is judgment and communication, not that your model won.

The problem was ambiguous. What did you do first?

Narrow it. Who is the user, what decision changes, what data already exists, and what a simple baseline would score. Ship a small version and learn, when the cost of that version is low. A long study with no decision is a weaker ending than a baseline in production and a list of what you still do not know.

What are they listening for?

Ownership, a clear sequence, comfort saying you were wrong, and a reason you chose the simpler model when it was enough. Match the detail to the role. A research interview wants the ablation. A product interview wants the decision and the measured outcome.

Coding-interview problems

State the input, the output, and the constraints. Give the brute force and its cost, then the improvement. Test an empty input, a single element, duplicates, and their example.

How do you talk about complexity?

Time is how the work grows with the input size. Space is extra memory beyond the input. A nested loop over n items is O(n²). One pass with a hash map is O(n) time and O(n) space. Sorting is O(n log n). Say both. “Faster” is incomplete until you say what you spent to get it.

Hash map: two-sum, and group anagrams

Use a map when the question is “have I seen the counterpart already?” Two-sum stores each value’s index, and for the next value asks whether target - value is already there. That is one pass. Group anagrams keys each word by its sorted characters, or by a count of its letters, and appends the word to that bucket. The buckets are the groups.

Two pointers: pair sum on a sorted array

Put one index at the start and one at the end. If the sum is too small, move the left index right. If it is too large, move the right index left. Each step throws away a whole region, so the scan is linear after the array is sorted. State whether the problem requires a pair of indices, a pair of values, or a count, and whether the same element may be used twice.

Sliding window: longest substring without a repeat

Use a window for a contiguous subarray or substring with a constraint. Advance the right edge to grow. Advance the left edge until the window is valid again. For a substring with all unique characters, keep a map of the last index of each character, and jump the left edge past the previous copy. The answer is the maximum window length you observed.

Binary search: a sorted array, or a yes/no boundary

Use it when the array is sorted, or when the answer space is monotonic: a property is false, then stays true. Keep the half that must contain the answer. Prefer a loop invariant you can say out loud, such as “the target is inside this closed interval,” and update the ends so the interval shrinks. The version that shows up in modeling work is searching a threshold: the smallest score cutoff that still meets a recall target.

BFS and DFS

BFS uses a queue and finds the shortest path in an unweighted graph, in number of edges. DFS uses a stack or recursion and is how you explore every path or flood a region, as in “number of islands” on a grid. Mark visited nodes as you enter them, or the search will loop. On a grid, the neighbors are the four adjacent cells, unless the problem includes diagonals.

Heap: top k

A min-heap of size k holds the k largest items seen so far. Each new item costs O(log k), so the scan is O(n log k). Sorting the whole input is the simpler answer when n is small or you need a total order anyway. Say which one you are choosing and why.

Dynamic programming, the three things to say first

Use it when a brute-force solution repeats the same subproblem while searching for an optimum or a count. Before coding, state the state, the recurrence, and the base case. Climbing stairs: the number of ways to reach step i is the sum of the ways to reach i−1 and i−2. Coin change: the fewest coins to make amount a is one plus the minimum, over each coin, of the fewest coins to make a minus that coin. Then fill a table. If they ask for the combination rather than the count, store a predecessor as well.

What do data-science coding rounds actually ask?

Count with collections.Counter. Deduplicate while keeping order. Merge overlapping intervals. Parse a list of records and aggregate in plain Python when pandas is disallowed. Implement precision, recall, or a confusion matrix from two label arrays. Talk through the empty case and the tie. If pandas is allowed, the same questions become groupby, a merge, and a check that the join did not multiply rows.
